# Hack-2-Optimize-2025

Welcome to the Hack2Optimize 2025 project! This repository is used to submit hackathon entries. Each team will have their own branch to work on and should push their code to their respective branches.

## Project Structure

- `main` branch: Contains the initial setup and guidelines for the hackathon.
- `team-<team-name>` branches: Each team will have a dedicated branch named `team-<team-name>` where they can work on their project.

## Instructions for Teams

1. **Clone the Repository**: Clone the repository to your local machine.
    ```bash
    git clone <repository-url>
    ```

2. **Create Your Branch**: Create a branch for your team using the naming convention `team-<team-name>`.
    ```bash
    git checkout -b team-<team-name>
    ```

3. **Work on Your Project**: Develop your project within your team's branch. Make sure to commit your changes regularly.

4. **Push Your Code**: Push your code to the remote repository.
    ```bash
    git push origin team-<team-name>
    ```

## Guidelines

- **Branch Naming**: Use the format `team-<team-name>` for your branch.
- **Commit Messages**: Write clear and concise commit messages.
- **Code Reviews**: Review code changes before merging to ensure quality and consistency.
- **Documentation**: Document your code and provide necessary instructions for running your project.

## Contact

If you have any questions or need assistance, please reach out to the hackathon organizers.

Happy hacking!
